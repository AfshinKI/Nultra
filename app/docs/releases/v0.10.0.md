# v0.10.0

- Scenes on iPhone and Android: create named groups, choose lights, and switch each group on or off from the home screen. Lights can belong to multiple scenes. View and edit membership from switch details; edit or delete scenes without deleting lights.
- iPhone widgets can select All On, All Off, individual lights, and scenes. Taps run in the containing app's background intent window without requesting the app to open. Android widgets also support scenes.
- Widgets show last-reported switch state. Background refresh is enabled by default with a requested interval of 15, 30, or 60 minutes (default 30). Configure and enable the backup server for background battery and state readings; low-battery notification settings still apply.
- Background timing is controlled by iOS/Android and is not guaranteed. Network reachability, force-quit/force-stop, system Background App Refresh, and battery restrictions affect execution. Continuous background BLE monitoring is not provided. Widget commands retain bounded execution and report errors rather than claiming unconfirmed server completion.
- Settings shows the live active and queued transaction counts and the configured concurrency limit. The three-slot cap remains pending physical-radio load testing; it is not advertised as the phone's hardware maximum.
- The developer badge is full width and appears at the bottom of Settings.
