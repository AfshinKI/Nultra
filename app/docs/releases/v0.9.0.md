# v0.9.0

- Android home-screen controls now start at 2×1 and remain resizable.
- New iPhone widget with four, eight, or sixteen bulbs across small, medium, and large sizes. Edit each widget to choose saved lights. Requires iOS 17+; tapping a bulb opens Nultra to apply the requested power setting. Widget state is last reported, not live.
- Both apps use one power toggle on the switch detail screen.
- Optional low-battery notifications with a configurable 1–50% threshold (default 5%). Each switch alerts once until its reading recovers ten percentage points above the threshold that triggered the alert. Suppression survives app restarts. Notifications use received readings; there is no remote push service or monitoring while the app is stopped.
- Hosted builds require manual dispatch or explicit PR labels, with platform selection for diagnostics and opt-in simulator tests. Releases require main, validate both platforms, and use only the version tag as the title.
