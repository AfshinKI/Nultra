Nultra 0.5.0 makes switch control more compact and adds Apple Shortcuts.

- Smaller two-column cards with glowing yellow bulbs, blue/gray presence LEDs, and spinner-only progress.
- Three signal bars using the fancy UI thresholds; signal readings update at most every five seconds.
- Battery icon only on cards, with green fill or a small red fill below 10%; percentages remain in switch details.
- Apple Shortcuts: Turn All Off, Turn All On, and Set Switch Power. Actions open Nultra and use short BLE transactions.
- Developer details: Afshin Kashani and innovetron.com. Demo mode is at the bottom of Menu.


Nultra-Update-Server.zip contains the separate Pi feed service and this release's IPA. Follow its README for setup, private HTTPS trust, and read-only GitHub access. GitHub remains private.
