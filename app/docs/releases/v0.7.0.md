Nultra 0.7.0 — iPhone background Shortcuts and optional backup server

- iPhone Shortcuts no longer requests that Nultra open. Commands use bounded background execution, short BLE sessions, and immediate disconnect.
- Menu → Backup server adds an optional saved URL/port, enable switch, connection check, and explicit switch mappings. No server address is built in.
- Saved switches outside phone BLE range can use the existing fancy server for on/off. Nearby BLE remains preferred; duplicate names cannot silently target another switch.
- Server requests report queued status, not hardware-confirmed success. The existing server has no per-command completion receipt.
- Open Nultra once after updating to allow local-network access and configure the server. Use a trusted home network for HTTP. Re-add an old Shortcut action if it retains foreground behavior.
- Background/locked-phone execution and live BLE/server fallback still require physical iPhone acceptance; iOS controls runtime and permissions.
- Android APK is included with matching release version; Android control behavior is unchanged (direct BLE, no server fallback in this version).
- No VPN is added. Server code is unchanged.
