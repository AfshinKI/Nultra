# Nultra v0.11.0

- Shortcuts now return immediately after accepting a request. Bluetooth work continues in a bounded background task, with the enabled backup server tried after Bluetooth failure. Later failures end silently. Acceptance does not confirm that a physical switch changed; iOS may end background work. Invalid requests, demo mode, and busy state are still rejected before acceptance. Widget controls keep their completion reporting. Addresses #14.
- iPhone and Android now allow six simultaneous short transactions instead of three. Menu shows the read-only active count, queued count, and configured limit. This is an app limit, not a hardware maximum reported by the phone. Addresses #8.
- Local-first development and release tooling now avoids automatic GitHub runner use. The iOS scene UI test correctly reads the actual switch on iOS 27.
