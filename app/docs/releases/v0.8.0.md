Nultra 0.8.0 — Android backup server and background controls

- Add the Nultra home-screen widget and select all saved switches or one light. Off/On runs a bounded background action without opening Nultra. Android may show a brief active-service notification.
- Bluetooth connections remain brief and disconnect before server fallback. Rename and discovery stay Bluetooth-only; no server-only switches are silently added.
- Server OK means queued, not hardware-confirmed. No optimistic power update or automatic HTTP retry; failed and partial commands are reported.
- Install Nultra.apk over your current installation to preserve data. Open Menu → Backup server and choose Save and check. The server address starts empty and the feature disabled.
- iPhone behaviour is unchanged from v0.7.0; its IPA carries the matching release version.
